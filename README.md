# Laksh Learns

One Place For All Learning Resources. A curated directory of online courses from top educational providers.

## Features

- Browse courses from multiple providers (GeeksforGeeks, Scaler, Microsoft Learn, Google Skillshop, TCS iON)
- Search courses by title or description
- Filter by difficulty, category, and certification status
- Bookmark favorite courses
- Dark/light theme toggle
- Responsive design

## Usage

Open `index.html` in a browser or visit the [live site](https://lnaigal.github.io/Laksh-Learns/).

## Adding Courses

Edit `data/courses.json` to add or modify providers and courses. The site loads data dynamically from this file.
